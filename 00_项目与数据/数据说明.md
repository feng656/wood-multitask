## 1. 数据来源与体量

### 1.1 四个任务来源（训练使用）

| 任务来源 | 数据域 | train / val / test | 监督内容 |
|---|---:|---:|---|
| Ring-only（年轮） | Mokume | 660 / 144 / 132 | 年轮边界 + 距离场 + valid mask |
| VSB defect（缺陷） | VSB（Veneer Surface Benchmark） | 10,000 / 2,000 / 4,000（test 7,030 实例） | knot/crack 框与掩膜 |
| 分类裁剪 | VSB 裁剪 | 20,975 / 4,536 / 7,722（另有外部 test 3,055） | normal / knot / crack |
| Bridge（桥接） | Mokume + UruDendro | 194 / 58 / 69 | 同一张图同时有年轮 + 缺陷监督 |

- bridge 细分：train Mokume 156（26 物理组）+ UruDendro 38（8 物理组）；test Mokume 54 + UruDendro 15；test 实例 crack 192（UruDendro 185 + Mokume 7）、knot 19；
- **注意**：UruDendro train 的 414 个 crack 实例只来自 8 个物理组——「实例数 ≠ 独立训练样本数」；
- 类别契约：`normal` / `knot` / `crack` / `other`（ignore，不进一级分类损失）。

## 3. 数据格式

| 类型 | 格式 | 说明 |
|---|---|---|
| 图像 | RGB JPG/PNG | Mokume 256×256；VSB 2000–3800px 原图；UruDendro 大图 |
| 年轮 target | PNG | boundary / skeleton / valid：灰度 >0；distance：PIL 16-bit ÷ 65535（解码方式与 `loaders.py._load_ring` 逐行一致） |
| 缺陷标注 | LabelMe JSON | Mokume 主类为 rectangle（两角点）；UruDendro 为 polygon；polygon restore 映射 167/168 匹配（唯一未匹配 `other|outer_damage` 属 ignore） |
| 主 manifest | `manifest.csv`（19MB，本目录已复制） | 36,288+ 条分类记录 + 全任务角色/split/group_id；`ring_targets.csv` 2,827 条（服务器） |
| 分组 | `group_splits.csv` | train/val/test 无 sample_id、无物理组泄漏（已审计） |

## 4. 划分原则（不可违反）

1. train/val/test 固定（split_v1），不得为提升数字重划；后续新增物理组用 `split_v2` 版本化；
2. UruDendro4 后续 20–30 张缺陷丰富图只作最终外部测试，不进训练；
3. 原图、原年轮标注、原缺陷 JSON 一律不修改，转换产物另存；
4. val 用于训练期选模型，test 仅最终低频评估一次。
